# Architecture Decision Records

ADRs record consequential architecture decisions and their status. A proposed decision is not implementation evidence.

Status vocabulary:
- **Proposed:** recommended, awaiting validation.
- **Accepted:** approved as the project baseline.
- **Superseded:** replaced by a later ADR.
- **Deprecated:** no longer recommended.

Each ADR should state context, decision, consequences, alternatives, and review triggers.
